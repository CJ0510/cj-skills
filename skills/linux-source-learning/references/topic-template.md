# Reusable Topic Note Template

Adapt this template; omit sections that add no value.

```markdown
# <Topic>

## Learning objective
What should the learner be able to explain, trace, predict, verify, or debug?

## Problem and boundary
Why does the mechanism exist? What is in and out of scope?

## Kernel position
Version, subsystem, source locations, and a compact architecture map.

## Mental model
A short causal explanation in the learner's own terms.

## Core data model
Important objects, ownership, lifetime, fields, and relationships.

## Main execution path
Entry, key decisions, state transitions, invariants, and exit/handoff.

## Core implementation
Only the calculations, branches, locking, ordering, and edge cases that change understanding.

## Why and tradeoffs
Problem, design, code, and tradeoff rationale with evidence and uncertainty labels.

## Version and history
Baseline behavior, later evolution, motivation, and stable concepts.

## Verification
Question, prediction, setup, measurement, expected/actual observation, interpretation, and failure analysis.

## Engineering implications
Consequences for correctness, latency, throughput, scalability, power, observability, or debugging.

## Mastery check
Explain, trace, predict, debug, and modify prompts.

## Summary and next topic
What problem is solved, how, why this design, and the next causal dependency to study.
```

Do not fabricate source snippets, results, history, or citations to fill the template.
